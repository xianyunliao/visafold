A personalized visa eligibility assessment tool for Chinese passport holders. Select your destination, visa type, and personal background, and visafold generates a tailored assessment based on your travel history, financial support, education, itinerary, and other key factors.

Covers Japan, South Korea, Singapore, the United States, the United Kingdom, Australia, New Zealand, and the Schengen Area. Supports tourist visas, working holiday visas, and work visas for applicants with an existing job offer.

## 当前版本：参考评分与申请准备

中文、全选项、无注册、无证件上传。报告以签证参考评分为主，补充资格初筛、材料准备、递交路径、准备建议和官方来源。评分是本站的经验参考指标，不是统计获签率或官方打分。打工度假按适用项目开放，已有Offer不能代替工作许可资格。29个申根成员国可分别选择。

### 本地使用与发布

```sh
python3 -m http.server 4173
```

浏览器打开 `http://localhost:4173`。静态托管以根目录发布，无需构建。运行必需文件：`index.html`、`styles.css`、`app.js`、`policy-data.js`、`material-rules.js`、`visa-engine.js`。`tests/`、`scripts/`、`research/` 不参与页面运行。

### 问卷与缓存

- 年龄选项为“18–22、22–29、30岁及以上”。第一档对应18周岁至未满22周岁，已满22周岁选第二档。新加坡25岁、新西兰30岁等边界追加精确选项。
- 户籍、常住地、递交地及居住依据分别询问。日韩旅游中，户籍与常住申请地一致加4分，异地申请且居住依据已准备也可加4分；用户选择受理方已确认户籍相关申请便利时另加6分。确认结果来自用户选项，未核实的省市优惠名单不作自动匹配。修改户籍、常住地、递交地或已选入境次数后，需重新确认适用性。
- 按目的地、签证具体类别、身份、资助及领区生成材料组，区分全部、任选路径、支持材料、待确认清单。任选组须选择一条完整路径，进度只计一组；未指定路径的笼统“已准备”不会误计。
- 分数由当前答案重新计算。切换目的地／类型清理不适用的旧答案；结果页可修改并重新计算。
- PNG和文字导出包含完整限制、材料、建议与来源，不截掉后面的风险。

### 个性化材料与精简选项

- 日本：选择适用的中国高校学生／毕业三年内单次个人旅游简化路径后，不再问资助人年收入，也不展示一般经济能力材料包。保留基础文件及适用性确认；多次、专科或未确认资格不自动免交。
- 韩国：仅选择成都领区、单次普通旅游时展示公开C-3-9替代经济证明和学生／指定城市非集体户籍免交路径。其他领区、多次及其他访问目的保留专属清单确认，不将成都表格当成全国统一条件。
- 新加坡：30天内普通旅游只显示护照、SG Arrival Card与行程费用准备；打工度假按在读生整组材料与毕业生学位／成绩单任选区分，不问通用语言考试和保险题。
- 新西兰：旅游区分本人资金、预付住宿后的资金、合资格正式担保人三条路径；离境票／额外购票资金／适用的正式担保另计一组。中国打工度假资金、学历、语言、保险独立符合；已有资格回答直接复用。
- 澳大利亚462：身份材料、学历、功能英语、资金与健康分开；学历及英语各有可选路径。600按ImmiAccount清单确认，不套用462。
- 英国：普通访客资金、学习／工作等按实际情况选用支持材料，不统一要求机酒预订、房产或保险；Skilled Worker的本人生活费、CoS雇主承担、持签在英满12个月等路径择一。
- 申根：申请、保险、访问目的／住宿／资金／离境等类别同时覆盖；具体文件依国家及领区。荷兰旅游已增加身份和本人付费分支，其余国家保留国家专属补充清单确认，不能声称29国细则都已逐项核实。
- 只问出资路径相关的年收入；删除重复同行人／国内联系题；毕业生跳过预计毕业；院校所在地仅在新加坡打工度假询问；改变背景回答会清除旧材料状态，避免旧路径被算成已准备。
- 问卷版本3保留版本2的背景回答，重置旧材料状态。材料可默认“暂不清楚”直接查看报告，仍可随后更新。

### 参考评分

保留旧版48分基础分，结合教育与身份、行程可用资金、出资人收入、资助关系、返校／离境安排、出境记录、拒签与逾期记录、入境次数，以及工作项目条件加减分。所有贡献在页面、文字和图片报告中完整显示；材料清单的准备状态单独统计，不改变背景评分。

- 日韩户籍便利加分仅在旅游路径、用户确认本次适用时生效，其他国家及工作类别不套用。日本学生简化分支另显示6分路径便利，替代不再询问的普通资金支持项，避免因免交材料而反向降低背景评估。
- 资格仍待确认时扣10分，上限89；存在明确资格限制时上限25；一般参考评分上限95。范围调整也计入明细，确保明细与总分一致。
- 符合新加坡短期免签或不支持的项目不生成签证分数，显示对应建议。
- 评分权重由本站设定，不是使领馆标准，也不代表真实获签概率。日韩官方细则尚未完整核实，不能据此宣称某省市天然更易获签。

### 政策维护

`policy-data.js` 保存官方来源、核验日期和具体范围；`material-rules.js` 管理目的地清单、AND/OR证明路径及准备状态；`visa-engine.js` 执行资格判断、评分及报告规则；`app.js` 处理选项、校验、缓存和导出。

材料核验依据及读取失败记录保存在 `research/material-review.json`（2026-11-18），包含澳大利亚PDF提取和网页人工核对范围。先前资格核验为 `research/rule-review.json`；早期记录为 `research/official-sources.json`。HTTP读取成功不等于规则已经核验，动态空壳和官方首页也不能代替实际类别原文。

维护步骤：

1. `python3 scripts/review_sources.py` 获取官方页面快照，需要网络。脚本仅更新快照，不自动改规则。
2. 阅读对应类别、护照及领区原文，核对有效日期与例外。
3. 在 `policy-data.js` 更新规则范围与 `reviewedAt`；必要时同步修改引擎和选项。
4. 运行测试、检查未知和不适用场景后再发布。

日本、韩国、美国部分页面限制读取；已通过网页检索核对日本学生单次旅游简化及韩国成都中心公开2025-07-03版C-3-9材料。韩国规则不套用其他领区或多次；美国访客面谈基础材料已通过官方网页核对，当地预约及面谈适用细则仍待完整核实。澳大利亚462已核对使馆2026年3月版中国清单及功能英语细则，600仍以账号个性清单为准。不能宣传为完整政策都已确认。各申根国家入口也不代表国家工作、材料和领区规则都已逐项核验。网站没有实时名额、自动政策更新、订单或兑换码验证。

主视觉图片与字体仍使用外部资源；问卷、规则和报告生成不依赖外部API。面向大陆用户发布时可进一步将视觉资源本地化。
